## Essentials

- [x] Sharing & collaboration (15 min): sharing pages, working and brainstorming with a team, in person or remote
- [x] Notion Essentials Quiz

## Workflows
[Path](https://academy.notion.com/page/workflows-catalogue) · ~50 min. Connected systems that link teams and projects, with some help from AI.

- [x] An issue tracker for any team (15 min): an intake system built with forms, charts and automations
- [x] Project management (15 min): projects and tasks databases with enough structure, but flexible
- [x] Notion Workflows Quiz

## Advanced
[Path](https://academy.notion.com/page/advanced-catalogue) · ~70 min. Automation, workspace architecture and the more complex features.
- [x] Workspace design (10 min): picking the right blocks for each use case and organizing databases
- [x] Database organization strategies (20 min): choosing a database structure, data modeling, connecting information across teams and keeping it maintained
- [x] Formulas (20 min): formulas to automate workflows and build dynamic databases, with help from Notion AI

[Path](https://academy.notion.com/page/notion-ai-catalogue) · ~90 min. From personal use of Notion Agent to Custom Agents for a team and rolling AI out to a whole organization.

- [x] Custom Agents (30 min): agents that automate repetitive team work, run on a schedule or on triggers, and use the tools the team already has
- [x] Scale Notion AI in your organization (30 min): a trusted system of record, Custom Agents across teams, and governance
